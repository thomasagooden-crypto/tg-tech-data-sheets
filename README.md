# Thomas Gooden Technical Data Sheets

One PDF per product, grouped by family under `pdf/`.

Direct download link for any sheet:

```
https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/<family>/<PART>.pdf
```

e.g. `https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/ferrule-bends/FG00608LF.pdf`

Sheets are added here only once approved.

Parts with status "No data sheet" in the build kit STATUS.csv have no sheet (e.g. capillary barrel unions). The website should not show a data sheet button for them.

Sheets are generated from the build kit in the private `tg-tech-drawings` repo (`datasheet-build/`).

## Complete vs incomplete sheets
- `pdf/` holds **complete, approved** sheets only. `datasheet_index.csv` lists exactly these. The website may link to these.
- `incomplete/` holds approved sheets whose sizing chart still has blank dimensions (listed in `incomplete_index.csv`).
  **The website must never link to anything in `incomplete/`.** Claude moves a sheet from `incomplete/` to `pdf/` once its
  measurements are filled, and it then appears in `datasheet_index.csv`.

## Measurements needed
[Measurements_Needed.xlsx](Measurements_Needed.xlsx) shows, for every built sheet still waiting on dimensions, a snapshot of the sheet's dimension guide and sizing chart next to each measurement needed, with a yellow box to fill in (mm). A second tab lists parts not built yet.
[Measurements_Needed.csv](Measurements_Needed.csv) has the same list as plain text, one line per measurement still needed: part number, which dimension,
how to measure it, and an empty `value_mm` column to fill in (mm, one decimal place).

## Master measurements
[Master_Measurements.csv](Master_Measurements.csv) is the master list of every part (about 630): sheet status, link to its sheet,
and every dimension on the sheet (L, L1, L2, H, H1, H2, W, threads etc.). Blank = still needed, `-` = not used for that part.
`dimension_key` explains each family's dimensions. Regenerated by Claude every time sheets are added or completed.
