# Thomas Gooden Technical Data Sheets

One PDF per product, grouped by family under `pdf/`.

Direct download link for any sheet:

```
https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/<family>/<PART>.pdf
```

e.g. `https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/ferrule-bends/FG00608LF.pdf`

| Family | Folder | Sheets |
|---|---|---|
| Hex nipples (standard, reducing, parallel) | `pdf/hex-nipples` | 38 |
| Elbows (F/F, M/F) | `pdf/elbows` | 22 |
| Adaptors (equal, reducing) | `pdf/adaptors` | 26 |
| Reducing bushes | `pdf/bushes` | 31 |
| Sockets (equal, reducing) | `pdf/sockets` | 20 |
| Ferrule bends (all types) | `pdf/ferrule-bends` | 14 |

Sheets are added here only once approved.

Sheets are generated from the build kit in the private `tg-tech-drawings` repo (`datasheet-build/`).
