# Thomas Gooden Technical Data Sheets

One PDF per product, grouped by family under `pdf/`.

Direct download link for any sheet:

```
https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/<family>/<PART>.pdf
```

e.g. `https://raw.githubusercontent.com/thomasagooden-crypto/tg-tech-data-sheets/main/pdf/ferrule-bends/FG00608LF.pdf`
